# Project guide

Read `ARCHITECTURE.md` before changing code. Keep its file map and behavior contracts current.
Use SwiftUI + MVVM: views present, view models coordinate, services handle disk/image/clipboard operations, models hold data.
Preserve the approved Quick copy interaction and minimal monochrome theme derived from the app icon.
Do not add hero copy, colored category cards, demo data in production, or full photo-library authorization for the system photo picker.
